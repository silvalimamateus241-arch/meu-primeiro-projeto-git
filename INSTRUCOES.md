# Instruções do Projeto

## Como usar
1. Clone o repositório pela URL pública que será disponibilizada no GitHub.
2. Leia o README.md.
3. Consulte comandos-git.txt e o histórico com `git log --graph --oneline --all`.

## Estrutura
- `README.md`: apresentação e reflexão final.
- `comandos-git.txt`: referência de comandos.
- `sobre-mim.md`: apresentação do autor.
- `INSTRUCOES.md`: instruções de uso.
- `.gitignore`: regras de exclusão.
- `arquivo-normal.txt`: exemplo versionado.

## Arquivos ignorados
`teste.tmp` e `senha.txt` são exemplos locais, não incluídos no GitHub.
Depois de clonar, recrie-os se quiser repetir o teste. Use apenas dados fictícios.
Confira com `git check-ignore -v teste.tmp senha.txt` e `git status --ignored`.
