## Reflexão final
1. **Qual a importância do Git para desenvolvimento de software?** O Git registra versões do projeto, permite comparar alterações e recuperar versões anteriores. Isso facilita corrigir erros sem perder todo o trabalho.
2. **Como branches ajudam no trabalho em equipe?** Cada pessoa pode desenvolver uma alteração em uma branch, enquanto a principal continua disponível. Depois, as alterações podem ser revisadas e integradas por merge.
3. **Por que escrever mensagens de commit claras?** Elas explicam o motivo de cada alteração e ajudam a encontrar quando um problema ou uma funcionalidade foi introduzido.
4. **Quando usar o .gitignore?** Para excluir do versionamento arquivos temporários, configurações locais e dados sensíveis. Ele não remove arquivos que já foram versionados; nesses casos é preciso tratar o histórico e, se necessário, trocar a credencial exposta.
5. **Como o histórico demonstra o aprendizado?** A sequência de commits deve mostrar a criação dos arquivos, o trabalho em branches, os merges e a resolução do conflito. O histórico deste repositório registra essas etapas, incluindo dois merges e um conflito real resolvido.
